# BEW WIKI

『나쁜 에메랄드 마법사 : MASKED』의 세계, 위자도의 설정을 모아 둔 위키입니다.

- 사이트: https://moncage-jae.github.io/BEWWIKI/
- 문서 원본: [`wiki/`](wiki/) 폴더의 `.md` 파일 (파일 이름 = 문서 제목)

사이트는 읽기 전용입니다. 문서는 이 저장소의 md 파일을 고쳐서 편집하고, 저장(Commit)하면 1~2분 뒤 사이트에 자동으로 반영됩니다.

---

## 편집하는 법

### GitHub 웹에서 고치기

1. 사이트에서 문서 위의 「편집」을 누릅니다. (또는 저장소의 `wiki/` 폴더에서 파일을 열고 연필 아이콘을 누릅니다.)
2. 내용을 고칩니다. `Preview` 탭에서 대략적인 모양을 볼 수 있습니다.
3. 오른쪽 위 **Commit changes…** → 무엇을 바꿨는지 한 줄 적고 → **Commit changes**.
4. 1~2분 뒤 사이트를 새로고침하면 반영되어 있습니다. 진행 상황은 저장소의 **Actions** 탭에서 볼 수 있습니다.

### 새 문서 만들기

- 사이트의 붉은 링크(아직 없는 문서)를 누르면 그 제목으로 새 파일 화면이 열립니다.
- 또는 저장소에서 `wiki` 폴더 → **Add file → Create new file** → 파일 이름을 `문서 제목.md`로 적습니다.

### 이미지 넣기

1. `wiki/images` 폴더 → **Add file → Upload files**로 이미지를 올립니다.
2. 문서에 `![[파일이름.jpg]]`라고 씁니다.

### 옵시디언으로 고치기

1. [GitHub Desktop](https://desktop.github.com/)으로 이 저장소를 내 컴퓨터에 받습니다 (Clone).
2. 옵시디언에서 **폴더를 보관함으로 열기**로 받은 저장소 폴더를 엽니다.
3. 문서를 고친 뒤, GitHub Desktop에서 **Commit to main** → **Push origin**을 누르면 사이트에 반영됩니다.

옵시디언의 `[[링크]]`, `![[이미지]]`, `> [!NOTE]` 같은 콜아웃, 속성(분류/상태/순서)이 사이트에서도 그대로 동작합니다.

## 문서 맨 위의 속성

```
---
분류: 인물
상태: 초안
순서: 1
---
```

| 속성 | 뜻 |
| --- | --- |
| 분류 | 왼쪽 메뉴와 「모든 문서」에서 묶이는 분류. 둘러보기 · 연대표 · 존재 · 인물 · 세력·단체 · 마법·개념 · 학문·문헌 · 지리 · 초안 원고, 또는 새 이름 |
| 상태 | `초안` 또는 `토막글`이면 문서 위에 알림 상자가 붙습니다. 확정된 문서는 비워 둡니다. |
| 순서 | 같은 분류 안에서의 순서. 작을수록 위. |

## 작성법

| 쓰는 법 | 보이는 모양 |
| --- | --- |
| `# 큰 제목` `## 소제목` | 문단 제목. 제목이 3개 이상이면 목차가 자동으로 생깁니다. |
| `**굵게**` | 굵은 글씨 |
| `[[문서 제목]]` `[[문서 제목\|보일 글자]]` `[[문서 제목#문단]]` | 다른 문서 링크. 없는 문서는 붉은 링크가 됩니다. |
| `본문[^1]` + 아래에 `[^1]: 각주 내용` | 각주 |
| `~~검열됨~~` | 검은 막대로 가려지고, 마우스를 올리면 보입니다. |
| `> [!DRAFT] 제목` / `> 내용` | 알림 상자. DRAFT · WARNING · SEAL · STUB · NOTE |
| ```` ```infobox ```` 블록 안에 `제목: 오즈` `이미지: full face.jpg` `항목: 값` | 오른쪽 정보 상자 |
| `#넘겨주기 [[문서 제목]]` | 첫 줄에 쓰면 다른 문서로 넘겨줍니다. |

## 폴더 구성

| 경로 | 내용 |
| --- | --- |
| `wiki/` | 문서 md 파일과 `images/` |
| `index.html` | 위키 사이트 화면 (보통 고칠 필요 없음) |
| `assets/` | 마크다운 변환용 라이브러리 |
| `scripts/build_manifest.py` | 문서 목록(`wiki/manifest.json`)을 만드는 스크립트. Actions가 자동으로 실행합니다. |
| `.github/workflows/pages.yml` | 저장할 때마다 사이트를 다시 배포하는 설정 |
